# لعبة التكاتف

مسابقة أسئلة عربية للأصدقاء. صُمّمت في **الرافعية** على يد **Vamos**.

- **شاشة المجلس:** شاشة مشتركة تعرض الأسئلة. يمسح اللاعبون رمز QR وينضمون من جوالاتهم للإجابة.
- **لعب عن بُعد:** غرفة برابط أو رمز مع شات للاعبين.
- **تحدّي البوتات:** اختر من خصم واحد إلى سبعة خصوم آليين ومستوى صعوبتهم.

الجولات تكمل تلقائيًا. يعرض الخادم نتيجة السؤال لمدة خمس ثوانٍ قبل الجولة التالية أو النتيجة النهائية.

## إضافة أسئلة

افتح [بنك الأسئلة](worker/questions.json) وأضف كل سؤال في نهاية الفئة المناسبة. ترتيب القيم هو السؤال، ثم الإجابة الصحيحة، ثم ثلاثة خيارات خاطئة. اللعبة تخلط ترتيب الخيارات عند العرض.

```json
["كم ضلعًا في المربع؟", "٤", "٣", "٥", "٦"]
```

استخدم `npm test` للتحقق من الأسئلة. إضافة الأسئلة في نهاية القائمة تحفظ معرّفات الأسئلة التي ظهرت في الغرف القائمة.

## التشغيل والتسليم

يتطلب المشروع Node.js 24. ثبّت الحزم بـ `npm ci`، ثم شغّل `npm run dev` وافتح http://127.0.0.1:4173. افتح تبويبات مستقلة لتجربة أكثر من لاعب على الشبكة المحلية أو نفس الجهاز.

راجع [ملف التسليم](HANDOFF.md) لمعرفة حالة المشروع وكيفية نشر التعديلات.
