# لعبة التكاتف

مسابقة أسئلة عربية للأصدقاء. صُمّمت في **الرافعية** على يد **Vamos**.

- **شاشة المجلس:** شاشة مشتركة تعرض الأسئلة. المضيف يسجّل اسمه ويجاوب من الشاشة نفسها، والباقون يمسحون رمز QR ويجاوبون من جوالاتهم. يكفي لاعب واحد مع المضيف للبدء.
- **لعب عن بُعد:** غرفة برابط أو رمز مع شات للاعبين.
- **تحدّي البوتات:** اختر من خصم واحد إلى سبعة خصوم آليين ومستوى صعوبتهم.

اختر طريقة الأسئلة: **كلاسيكي** (أربعة خيارات، نقطة للإجابة الصحيحة) أو **الخدعة** (كل لاعب يكتب جوابًا مزيّفًا، ثم الكل يدوّر على الصحيح بين الخدع: نقطتان لمن يعرف الصحيح ونقطة لصاحب الخدعة عن كل لاعب ينخدع). لكل فئة بنك أسئلة كلاسيكي في `worker/questions.json` وبنك أسئلة سردية بفراغ `____` للخدعة في `worker/bluff.json`.

اختر ٥ أو ١٠ أو ٢٠ جولة. بعد كل سؤال يظهر الترتيب خمس ثوانٍ وتبدأ الجولة التالية تلقائيًا. بعد السؤال الأخير يبدأ عدّ الحسم، ثم يظهر البطل والترتيب النهائي.

## إضافة أسئلة

يضم [بنك الأسئلة](worker/questions.json) أكثر من ٣٠٠٠ سؤال عربي في تسع فئات (منها «أفلام ومسلسلات» و«باب الحارة» من الجزء الأول إلى الخامس و«أعلام الدول»)، ويضم [بنك الخدعة](worker/bluff.json) أسئلة سردية لكل فئة، مع صور لأسئلة التعرّف البصري. أضف كل سؤال في نهاية الفئة المناسبة. ترتيب القيم هو السؤال، ثم الإجابة الصحيحة، ثم ثلاثة خيارات خاطئة. اللعبة تخلط ترتيب الخيارات عند العرض.

```json
["كم ضلعًا في المربع؟", "٤", "٣", "٥", "٦"]
```

لإضافة صورة، ضع ملف WebP أو SVG في `ui/questions/` وأضف قيمة سادسة للسؤال بالشكل `{"file":"example.webp","alt":"وصف يوضح ما في الصورة"}`. استخدم `npm test` للتحقق من الأسئلة. إضافة الأسئلة في نهاية القائمة تحفظ معرّفات الأسئلة التي ظهرت في الغرف القائمة. يحتفظ المتصفح بسجل الأسئلة التي ظهرت، وتستبعد الغرفة سجل المشاركين عند إنشاء المباراة أو الانضمام.

تتضمن الأسئلة صياغات أصلية وتمارين حساب ومنطق، بالإضافة إلى حقائق عن الدول والعناصر والرياضة والأدب والتاريخ. [Country Codes](https://github.com/datasets/country-codes) · [PubChem](https://pubchem.ncbi.nlm.nih.gov/periodic-table/) · [OpenFootball](https://github.com/openfootball/football.json) · [Open Library](https://openlibrary.org/developers/licensing) · [Nobel Prize](https://nobelprize.readme.io/reference/getting-started) · [World Factbook](https://github.com/factbook/factbook.json)

## التشغيل والتسليم

يتطلب المشروع Node.js 24. ثبّت الحزم بـ `npm ci`، ثم شغّل `npm run dev` وافتح http://127.0.0.1:4173. افتح تبويبات مستقلة لتجربة أكثر من لاعب على الشبكة المحلية أو نفس الجهاز.

لبناء نسخة تجريبية في صفحة واحدة بدون خادم (لمشاركة التعديلات قبل نشرها): `npm run preview` ثم افتح `dist/preview.html`.

راجع [ملف التسليم](HANDOFF.md) لمعرفة حالة المشروع، و[دليل النشر](DEPLOY.md) لنشر اللعبة مجانًا على Cloudflare Workers + D1 مباشرة من GitHub.
