# تحدّي الربع

لعبة أسئلة عربية على المتصفح. ينشئ المضيف غرفة، ويرسل الرابط إلى أصدقائه. يختار اللاعبون الفئة بالتناوب، ويجيب الجميع عن السؤال نفسه.

## إضافة أسئلة

افتح [ملف الأسئلة](worker/questions.json) وأضف سطرًا تحت الفئة المناسبة. كل سطر يحتوي السؤال، ثم الإجابة الصحيحة، ثم ثلاثة خيارات خاطئة. اللعبة تخلط ترتيب الخيارات عند العرض.

```json
["كم ضلعًا في المربع؟", "٤", "٣", "٥", "٦"]
```

أضف الأسئلة في آخر القائمة. اللعبة تستخدم موضع السؤال داخل الفئة للمحافظة على ترتيب الأسئلة التي ظهرت في الغرف المفتوحة. تحقق من التعديلات بـ `npm test`. يتأكد البناء من صيغة كل سؤال ومن تكرار نص السؤال والخيارات.

## التشغيل على جهازك

شغّل `npm run dev` باستخدام Node.js 24، ثم افتح http://127.0.0.1:4173. افتح رابط الغرفة في تبويب مستقل أو نافذة خاصة لتجربة لاعبين. تستخدم المعاينة قاعدة SQLite محلية منفصلة عن الموقع المنشور.

## البناء

يشغّل `npm run build` بناء Cloudflare Worker في `dist/server/index.js`. ملف `.openai/hosting.json` يعرّف مشروع Sites وربط D1. مخطط الغرف موجود في `drizzle/0000_rooms.sql`. انشر نسخة جديدة في Sites بعد تعديل المصدر حتى تظهر التغييرات على الموقع المنشور.
